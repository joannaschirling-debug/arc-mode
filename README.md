# Arc Mode

Joeys Struktur-App: Heute-Fokus statt starrer Lernblöcke, Termine aus dem Handy-Kalender, Routinen mit Verlauf, Pomodoro-Timer mit Umdrehen-Start.

- Web (PC): `npm run dev` bzw. GitHub Pages
- Android: Capacitor, APK wird von GitHub Actions gebaut (Releases)
- Daten: Supabase (`supabase/schema.sql`), lokal-first mit Sync
